# Cardiologist Website Template (AGENTS.md)

This project contains the premier, empathetic, and human-centric **Cardiologist & Cardiac Care Website Template** (Dr. Sanjay), engineered strictly according to all rules in `SKILL.md`.

## Core Technical & Architectural Constraints
1. **Target Hosting**: 100% compatible with static hosting on **GitHub Pages** (No Node backend, SSR, database, or API routes in production).
2. **Design System**: 60-30-10 rule (Deep midnight navy `#080E1A`, slate trust depth `#0F172A`, vital crimson heart accent `#E11D48`, ECG pulse cyan `#0EA5E9`, gold `#F59E0B`).
3. **Typography**: Friendly, humanist typography (*Plus Jakarta Sans* for headings, *Inter* for accessible clinical readability).
4. **Glassmorphism**: Ultra-premier frosted glass cards with soft borders, backdrop blur, and gentle hover elevations.
5. **Interactive Goal Navigator**: Empathetic tabbed navigation allowing patients to choose their exact health concern (*Angioplasty*, *Chest Pain*, *Heart Check*, *Palpitations*, *Blood Pressure*) dynamically updating advice and pre-filled booking actions.
6. **Swipeable Carousels**: Touch-swipe enabled carousels for Hero, Services, and Testimonials.
7. **Accessibility & Quality**: 48px touch targets, zero horizontal scroll overflow, and pre-filled WhatsApp link generation.
